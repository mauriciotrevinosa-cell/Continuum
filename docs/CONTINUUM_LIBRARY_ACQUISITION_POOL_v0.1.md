## Growth rule

The count of 49 is not a limit and not an application seed.

Mauricio may add a source later simply because he likes it, even if it will never appear in The Arrivals. That source can remain Library-only or become the basis for a separate Continuum project.

Likewise, a future source can be added to an existing project and be allowed to change that project's world rather than being forced into a frozen taxonomy.

## Vault rule

The current physical scaffold at `C:\ContinuumVault` is a convenience structure for this acquisition pool. It is personal user data, not a generic Continuum default.

Continuum must eventually discover/register arbitrary user Libraries rather than creating these 49 sources for every user.

## Relationship to The Arrivals

The Arrivals has its own project-specific source membership. That membership will be decided later from the Library and may change over time.

A source being present here does not approve its characters for The Arrivals, set an arrival priority, choose a canon snapshot, define a body/memory state, or imply any relationship.

Those decisions belong to project-level curation after source ingestion.
