## Decision

The Light Novel path is now active.

This does not erase or abandon manga production.

Current relationship:

```text
shared Story Canon
├── Light Novel — active reading / prose production path
├── Manga — active visual production path
└── future animation adaptation
```

The LN may expand pacing, interiority, sensory detail, connective dialogue and ordinary-life texture when prose requires it.

It may **not** silently change:
- story facts;
- chronology;
- relationships;
- power mechanics;
- wardrobe continuity;
- character essence;
- arrival timing;
- established motivations;
- locked callbacks/payoffs.

## Source discipline

Before drafting any LN chapter, re-read the narrowest authoritative source packet for the affected material.

Minimum:
1. current S1 Draft 1 for the episode;
2. Level-4 editorial overview where available;
3. applicable later audit/correction;
4. applicable integrated overlay/addenda;
5. relevant setting / wardrobe / character continuity;
6. current LN Style Bible + approved voice baselines.

If sources conflict:
- latest explicit creator decision wins;
- otherwise follow the project Story Constitution / authority order;
- preserve uncertainty rather than inventing a consequential answer.

## Current first production target

Season 1.

Volume grouping, chapter boundaries and chapter lengths are provisional and may change during prose production.

Episode is the stable story/canon umbrella.

LN chapter is a reading/adaptation subdivision.

Scene is the smallest source/provenance/dependency unit.

## Quality bar

The goal is a production manuscript, not a screenplay transcription.

Each chapter must:
- read naturally as prose;
- preserve character-specific voice;
- make manga-only acting legible without overexplaining it;
- remain traceable to S1 source material;
- carry enough scene texture to feel lived rather than summarized;
- avoid invented continuity.
