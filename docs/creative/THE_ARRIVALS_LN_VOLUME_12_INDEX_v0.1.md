## Volume function

The first rescue did not solve the Memory Arc.

V12 gives Rem, Kaneki and Aira presence before the rescue, preserves Ori's damaged but understandable choice, uses the McLaren cap as a mundane continuity clue, allows Rimuru/Raphael to stabilize without becoming identity authorities, and closes the dominant Memory movement on changed behavior rather than perfect autobiographical certainty.
