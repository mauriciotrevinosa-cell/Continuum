# Stage 4 Production QC

## Hard canon checks
- Raphael never perceives/detects The Noise.
- No deliberate analysis/provocation of Mau.
- No outward explosion/aura/power contest at collapse.
- Only Rimuru clearly hears `Raphael.`
- Frieren does not learn exact word in E6.
- Mau memory ends around Rimuru greeting and resumes on waking.
- Nobody tells Mau he said `Raphael`.
- Rimuru/Raphael decide against repeating any attempt.

## Visual language
- Mau's subjective overload may use broken typography/abstract fragments, but must not resemble a functional system UI.
- Raphael internal presentation and Mau subjective Noise presentation must be visually distinct so readers do not infer Raphael is reading it.

## Character
- Frieren distrust is protective, not irrational hostility.
- Rimuru remains friendly and genuinely confused/guilty.
- Yuta is calm mediator/protector.
- Bocchi concern appears through presence/guitar/practical help.

## Environment
- Five-person occupancy changes composition but not renovation level.
