# The Arrivals — S1 Production Calibration Chapter v0.1

**Status:** CREATOR-APPROVED PRODUCTION CALIBRATION PACKAGE / NON_CANON  
**Project:** `The Arrivals`  
**Branch:** `creative/s1-season-board-v0.1`  
**Purpose:** create one compact but broad visual-production chapter that exercises the recurring Season 1 cast, environments, wardrobe, acting, crowd work, action and high-intensity effects before official canon rendering begins.

This is a **production calibration chapter**, not an extra canon episode and not a replacement for any approved S1 panel script.

It deliberately re-materializes approved or creator-directed Season 1 beats as isolated calibration pages. The purpose is to establish what the manga should look and feel like when the official run begins.

---

## 1. Why this exists

Official S1 should not begin by calibrating only the literal first manga page. The opening pages do not contain Mau and do not represent most of the recurring production problems that dominate the season.

Before official canon rendering, the production system should prove that it can repeatedly handle:

- the abandoned settlement / future base;
- the inn in both ruined and lived-in states;
- the lake;
- roads / forests / travel;
- the mercantile town and guild crowds;
- all nine recurring G1 + G2 characters;
- Mau's creator-grounded wardrobe and readable story-significant clothing details;
- borrowed layered wardrobe without identity leakage;
- quiet acting and close relationships;
- household ensemble composition;
- simple combat;
- G3's visual introduction;
- Sukuna and one high-intensity supernatural composition.

The calibration chapter therefore acts as the **base visual grammar / house-style benchmark for S1**.

It is not a style prison. Later episodes, chapters, POV sequences or special dramatic sections may intentionally use a different visual mode when the story benefits from it. A Spider-Verse-like principle is allowed: individual characters or sections can carry a stronger visual identity without destroying overall continuity. Any such deviation should be deliberate and scoped, not accidental drift.

---

## 2. Canon and continuity boundary

This run must be created as a dedicated **NON_CANON production calibration run**.

Rules:

1. Calibration renders never become story events merely because the creator approves their visual quality.
2. Calibration approval does **not** add these pages to official manga continuity.
3. Official canon pages may use approved calibration output as visual reference for style, environments, wardrobe and appearance, but not as previous-story continuity.
4. A calibration page can never authorize an absent story element. Example: approving the Sukuna calibration page does not permit Sukuna to appear in E1.
5. Production Models and confirmed Vault grounding remain authoritative for identity. A calibration render may reinforce a correct character design but may not override approved identity evidence.
6. Wardrobe remains separate from identity. Borrowing Mau's clothing never transfers Mau's physical identity to another wearer.
7. Old TEST renders / TEST-approved technical artifacts must not enter this calibration run's art continuity.
8. The calibration run itself must not enter the official canon run's art continuity as prior story pages.

---

## 3. Visual-source precedence

When producing a calibration page, use the narrowest relevant source material rather than sending the whole Vault.

Production authority order:

1. the exact approved/creator-directed source beat named for that calibration page;
2. approved Character Production Model identity refs for the characters on that page;
3. story-appropriate approved wardrobe set for that page/stage;
4. confirmed page-specific grounding refs;
5. approved calibration references relevant to the same character/environment/visual function;
6. approved grammar / technique / environment references.

Unconfirmed candidates must never become identity conditioning.

The calibration chapter itself should become a useful benchmark only **after creator review**. It must not bootstrap its own mistakes into later pages.

# 7. Review and revision semantics

The calibration reader should support natural reading first and production controls second.

## Default reading interaction

Controls should be visually unobtrusive and may auto-hide when the pointer is idle, reappearing on pointer movement / interaction in a Netflix-like way.

The creator should be able to simply read through the chapter without repeatedly clicking `approve` on every page.

## Chapter-completion approval

When the creator reaches/completes the chapter through the intended review UI, the currently selected versions may be treated as the creator-approved calibration set.

This is a **human interaction**, not permission for an agent/test to fabricate approval.

## Approval is not deletion-proof finality

A previously approved page may later look worse on reread or become improvable after the production stack improves.

Therefore:

- the creator may reopen an approved page;
- a later revision may replace it as the current approved version;
- the older approved artifact is never deleted;
- the old artifact remains in an immutable history/safe as `previously approved / later superseded` or equivalent provenance;
- official pages that were generated while the older version was current retain provenance to exactly what they used.

## `UPGRADE QUALITY`

Use when the creator likes the semantic page — staging, cast, outfits, expressions, layout and story meaning are correct — but wants higher fidelity / cleanup / detail / resolution.

An upgrade should preserve the page's semantic intent and lineage.

## `REGENERATE`

Use when the page itself is wrong or unsatisfactory: incorrect character, bad staging, nonsensical object, wrong clothing, wrong expression, poor composition, accidental extra character, or other semantic failure.

Regeneration creates a new candidate version. It does not erase the old render.

Example: if Sukuna appears in an E1 page where he is not in the source beat, that is a regenerate/reject issue, not an artistic reinterpretation.

# 9. Exit criteria before official S1 manga begins

The calibration chapter is considered sufficient to begin official canon production when the creator is satisfied that:

- G1 + G2 are recognizably and repeatably on-model;
- the recurring inn / village / lake / mercantile environments are stable enough to reuse;
- Mau's core wardrobe reads correctly;
- borrowed wardrobe resolves without identity leakage;
- group scenes do not duplicate/lose characters;
- quiet acting works;
- simple action works;
- G3 and Sukuna have usable base designs;
- the production stack can deliberately shift intensity/style without uncontrolled drift;
- page revision, quality upgrade and history retention work as expected.

This does **not** require every calibration page to be flawless on its first render. The chapter exists so the creator can find and correct those failures before official canon pages accumulate downstream dependencies.

# 10. Handoff to implementation

Implementation should consume this file as data/source direction rather than hardcoding `The Arrivals` assumptions into generic production architecture.

Required behavior:

- materialize/start this as a dedicated NON_CANON calibration chapter/run;
- preserve each CAL page's source locator and notes;
- keep calibration continuity isolated from official canon continuity;
- use the normal W8 minimal/reference-safe bundle builder;
- allow creator review, quality upgrade, semantic regeneration and later supersession without deleting earlier approved artifacts;
- do not mark any page approved on the creator's behalf during setup/tests;
- if a real GPU/provider is not configured, expose truthful READY/BLOCKED state rather than fabricating output;
- once a real backend is available, creator can start CAL-01 locally and proceed through CAL-16 in the reader.

After this chapter is visually calibrated, official S1 production can begin from the actual approved S1 episode/page scripts rather than from this sampler.
