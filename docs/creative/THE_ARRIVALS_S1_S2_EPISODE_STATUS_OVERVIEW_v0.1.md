The generator is no longer limited to S1E1 because of missing story panelization.

**Panel scripts currently exist in Git for S1E1–S1E12.** Continuum may ingest those episodes as Level-4 source material.

Recommended M3 rollout remains conservative:

1. start with the approved **S1E1 chapter package** as the first real generation target;
2. make attempts consume the reference manifest;
3. validate generation, lineage, review, approval, and persistence;
4. then allow the pipeline to take S1E2–S1E12 as additional Level-4 inputs;
5. S1E13 joins once its panel script/QC is completed;
6. S1E14–S1E19 join sequentially as they reach Level 4.

M2 remains a workflow/synthetic smoke-test layer; real manga generation depends on M3/local-model integration.
