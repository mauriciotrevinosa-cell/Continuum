# The Arrivals — Light Novel — Volume 17
## Chapter 18 — Mau Hears Everyone

**Status:** LN PRODUCTION DRAFT  
**Version:** 0.1  
**Volume:** 17  
**Reading order:** 18  
**Source episode:** S3E51 — `Questions`

Mau heard the worst sentences accidentally.

"I never asked to come here."

True.

"My mother is there."

True.

"If I return, maybe I can fix what I left."

Maybe.

"I want to stay, but I don't know if that's because I'd feel guilty leaving."

Important.

"I love people here."

Also true.

"I miss home every day."

No contradiction.

"I would go back if I knew I wouldn't regret it."

There.

That sentence stayed.

Mau heard versions from different people.

Regret.

What if.

Wrong choice.

A lifetime wondering.

The Trial had asked whether people would choose him.

Mau's mind built a different problem.

What if choosing itself hurt them?

What if love made them stay when they wanted home?

What if gratitude became a cage?

What if Frieren stayed because leaving Mau felt cruel?

He knew better than to decide that was true.

Memory Arc had taught him uncertainty.

Unfortunately, uncertainty could support fear too.

The goddess's Return line returned:

`DREAMLIKE IN RECOLLECTION.`

Mau thought:

If Continuum became a dream, maybe leaving would not feel like losing a life.

That thought was compassionate.

That thought was dangerous.

It did not become a plan immediately.

That would have been easier to stop.
