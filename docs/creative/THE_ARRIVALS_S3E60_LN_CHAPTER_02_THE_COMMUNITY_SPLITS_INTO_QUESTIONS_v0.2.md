# The Arrivals — Light Novel — Volume 19
## Chapter 26 — The Community Splits Into Questions

**Status:** LN PRODUCTION DRAFT — REBUILD v0.2  
**Volume:** 19  
**Reading order:** 26

The settlement did not split into camps.

It split into questions.

Can couples choose differently?

Can children return without guardians?

What happens to a family formed from different worlds?

Can someone stay now and return later?

Does petition happen before commitment?

Can the loved person refuse?

What if source world is dangerous?

What if returning restores obligations you escaped?

What if Continuum becomes dreamlike?

What if it doesn't?

Arrival House created a private room for choice consultations.

Not public board.

No tally.

No STAY column.

No RETURN column.

A person's answer was not settlement data.

Some argued anyway.

Staying obvious.

Returning obvious.

Both sentences hurt somebody.

The council issued one rule:

No campaigning inside Arrival House.

Information.

Not pressure.

The Goddess had created a choice.

The settlement now had to avoid turning choice into loyalty test.
