# The Arrivals — Light Novel — Volume 19
## Chapter 27 — Future Regret

**Status:** LN PRODUCTION DRAFT — REBUILD v0.2  
**Volume:** 19  
**Reading order:** 27

Mau wrote scenarios privately.

Not deals.

Not yet.

If everyone chooses separately.

If couples split.

If someone stays for love and regrets it.

If someone returns and loses Continuum memory.

If memory stays vivid enough to hurt.

If it fades enough to feel betrayal.

If Frieren stays because leaving him feels cruel.

He stopped.

Started again.

He knew the thought was unfair to her.

That did not make fear disappear.

The Return clause:

may become dreamlike.

If a life became dreamlike, perhaps grief would soften.

Compassion.

Danger.

Mau recognized both.

He showed none of the pages to anyone.

That was first real mistake.

Not because private thinking was wrong.

Because the pages had become planning.

He told himself:

I'm only exploring options.

Technically true.

The worst lies often survived by staying technically true.
