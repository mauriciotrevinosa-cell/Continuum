# The Arrivals — Wardrobe v1 creator direction v0.1

Status: CREATOR DIRECTION / PROVISIONAL / READY FOR REFERENCE INTAKE

Purpose: lock the current narrow wardrobe direction before detailed reference intake and Production Model wardrobe work. This is intentionally small enough to support the opening arc without designing the full S1 closet.

## Global opening-arc rule

The opening of The Arrivals takes place in autumn moving toward early winter. Wardrobe should therefore feel practical for travel, layering and cooling weather.

For the early arc, keep each main character to a small number of meaningful outfit variants. Clothing continuity and garment state changes are preferred over unnecessary costume churn.

## Frieren

Initial wardrobe target:

1. DEFAULT / CLASSIC TRAVEL LOOK
   - Primary recognizable outfit.
   - Main identity-safe production wardrobe for early pages.

2. COLD-WEATHER / WINTER TRAVEL VARIANT
   - Same core visual identity with added cold-weather layering suitable for late autumn / early winter.

State variants may include clean, lightly dirty, wet or travel-worn versions without counting as new outfits.

## Mau — wardrobe identity direction

Mau's wardrobe should feel personally recognizable, contemporary, practical and lived-in rather than generic fantasy costuming.

A strong creator-grounded direction is to draw from the creator's actual clothing habits, especially:

- motorsport jerseys
- motorsport polos
- McLaren hoodie
- Ferrari polo
- Ferrari button shirt
- bucket hat
- simple jeans
- bomber jacket
- small backpack / daypack

These pieces should not all be worn at once. The wardrobe should be assembled as a small, believable travel closet with repeat use and state continuity.

### Mau early outfit structure

M1 — MAIN CASUAL / TRAVEL

- one recognizable upper layer or top from the creator-grounded wardrobe
- jeans or similarly simple practical bottoms
- simple travel footwear
- optional small backpack

M2 — SECOND CHANGE / ALTERNATE TRAVEL

- a second top or layer from the same wardrobe language
- may use a polo, motorsport jersey, button shirt or alternate outer layer
- same or similar practical bottoms are acceptable
- bucket hat may appear when compositionally useful

The intent is to give Mau a believable second change without creating an implausibly large closet at the start of the story.

## Garment-state continuity

Between E1 and E2, clothing may become dirty, worn or damaged from travel/events. A later change of clothes can therefore be motivated naturally by garment condition rather than arbitrary costume rotation.

Dirty / damaged / repaired versions of the same garment are continuity states, not separate identity designs.

## Bomber jacket story object

The bomber jacket should be treated as a continuity-bearing garment.

Provisional narrative progression:

1. BOMBER — INTACT
2. BOMBER — TORN / DAMAGED BY THE MONSTER
3. BOMBER — REPAIRED BY RIMURU

When Rimuru repairs it, Mau should ask for the repair to remain visibly identifiable as a patch rather than being restored invisibly to factory-new condition.

The visible patch becomes memory encoded into the garment and can recur later as a visual callback.

## Motorsport-world clue

Creator-grounded motorsport clothing can later function as a narrative clue rather than mere branding/decor.

When Yuta eventually sees a recognizable motorsport garment/logo/style, he may plausibly react to it as evidence that Mau could be connected to Yuta's world or a closely related world.

This should remain subtle: the wardrobe is first a real part of Mau's identity, and only secondarily a story clue.

Do not overload the early wardrobe with many simultaneous branded pieces solely to force the clue.

## Production principle

Wardrobe is separate from identity.

The system should resolve:

CHARACTER IDENTITY
+ CURRENT / NARRATIVE-STAGE OUTFIT
+ GARMENT STATE
+ CONTINUITY

rather than encoding clothing as permanent character identity.
