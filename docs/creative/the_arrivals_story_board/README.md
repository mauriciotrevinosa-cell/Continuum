# The Arrivals — Story Board

**Purpose:** durable navigation and story-status layer for the narrative project **The Arrivals**.

This folder exists so story state is readable from one place even when implementation work happens on different Git branches. Branch age is **not** a canon level. The board records the latest known direction, links the underlying material, and separates:

- production-ready Season 1 material;
- approved/high-confidence Season 2 structure that is not yet manga-ready;
- major arcs whose story direction exists but whose exact episode placement is open;
- floating ideas that should not be lost;
- direction changes that were explicitly resolved;
- genuinely open questions that still need a creator decision.

## Authority / what is actually "law"

Story-status pages, inventories, audits and decision history are **records of story state**, not immutable creative law.

Durable creative rules live in:
1. [STORY_CONSTITUTION.md](./STORY_CONSTITUTION.md) — cross-season story/pacing/ensemble rules and authority hierarchy.
2. explicit later creator decisions, which may revise any older rule or story node.

A stale status/history sentence never overrides a later creator decision or the constitution.

## Start here

1. [STORY_CONSTITUTION.md](./STORY_CONSTITUTION.md) — durable creative rules: story determines episode count, ensemble presence is not mandatory, lived-space is real story, and status/history files are not law.

3. [S1_STORY_STATUS.md](./S1_STORY_STATUS.md) — all 19 Season 1 episodes and manga-production state.
4. [S2_STORY_STATUS.md](./S2_STORY_STATUS.md) — current S2 opening skeleton and unplaced S2 blocks.
5. [MAJOR_ARCS.md](./MAJOR_ARCS.md) — Sukuna / Hollow Purple / Second Chance, Mau–Frieren–Himmel, Ori, relocation/city, power secrecy.
6. [FLOATING_IDEAS.md](./FLOATING_IDEAS.md) — ideas without enough structure or exact placement yet.
7. [DECISION_HISTORY.md](./DECISION_HISTORY.md) — explicit changes of direction. These are **provenance/history, not law**.
8. [OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md) — only questions that still appear genuinely unresolved.

## Preserved source material

The folder also contains exact snapshots of the material needed to reconstruct the current story state:

- \`s1/drafts/\` — continuous S1 episode drafts where available;
- \`s1/manga_scripts/\` — S1E1–S1E19 panel scripts;
- \`s1/editorial_overviews/\` — Level-4 editorial overviews where available;
- \`sources/\` — status, overlay, S2 handoff and major-arc source documents.

For Season 1 production, the rule remains:

> approved base manga panel script + integrated cinematic revision overlay = current authoritative manga script.

The board summarizes; the preserved scripts remain the detailed production material.
