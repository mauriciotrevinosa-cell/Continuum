# The Arrivals — S1 LN Production Source Gate v0.1

**Status:** AUTHORITATIVE WORKFLOW RULE  
**Date:** 2026-09-28  
**Project:** `The Arrivals`

## Non-negotiable rule

> **Do not draft an LN chapter from memory when the S1 source exists.**

Every chapter begins with a source preflight.

## Source preflight

For the episode/material being adapted, inspect:

1. authoritative/current Draft 1;
2. Level-4 editorial overview if present;
3. applicable creator corrections made after the Draft 1;
4. integrated cinematic revision overlay;
5. applicable episode/project addenda;
6. spatial/environment continuity;
7. wardrobe continuity for every scene;
8. current S1 audit + LN readiness;
9. current LN Style Bible;
10. any approved LN voice baseline already established.

Only then draft.

## Allowed LN expansion

Allowed without changing canon:
- prose-native sensory detail;
- interiority that does not reveal knowledge early;
- clearer geography;
- connective tissue;
- additional mundane actions;
- dialogue needed to replace visual acting;
- breathing room;
- scene transitions;
- selectively expanded ordinary-life material;
- pacing expansion already promoted by the S1 audit.

## Requires creator/story authority

Do not invent or silently decide:
- new plot event;
- new arrival;
- new relationship status;
- new power/mechanic;
- new backstory fact;
- new wardrobe item;
- altered chronology;
- changed causal relationship;
- solved mystery;
- character motive not supported by source;
- explicit emotional category the character has not reached yet.

## Character rule

The move to prose never gives permission to smooth the cast into one LN voice.

Every expansion must grow from the character's existing:
- cadence;
- humor;
- blind spots;
- emotional range;
- social reflexes;
- knowledge;
- habits;
- pressure behavior.

## Source ledger inside LN documents

Each production chapter should record in its metadata:
- source episode;
- primary draft;
- applied audit/corrections;
- relevant addenda/bibles;
- chapter status.

The printed reading text does not need to expose this metadata, but Continuum must retain it.

## Review semantics

A chapter can be:
- DRAFT;
- REVIEW;
- APPROVED;
- LOCKED;
- SUPERSEDED.

Approval of LN prose approves the adaptation, not a change to shared Story Canon.
