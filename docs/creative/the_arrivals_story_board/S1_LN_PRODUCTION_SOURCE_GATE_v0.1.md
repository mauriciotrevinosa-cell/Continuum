# The Arrivals — S1 LN Production Source Gate v0.1

**Status:** AUTHORITATIVE WORKFLOW RULE  
**Date:** 2026-09-28  
**Project:** `The Arrivals`

## Non-negotiable rule

> **Do not draft an LN chapter from memory when the S1 source exists.**

Every chapter begins with a source preflight.

## Source preflight

For the episode/material being adapted, inspect:

1. authoritative/current Draft 1;
2. Level-4 editorial overview if present;
3. applicable creator corrections made after the Draft 1;
4. integrated cinematic revision overlay;
5. applicable episode/project addenda;
6. spatial/environment continuity;
7. wardrobe continuity for every scene;
8. current S1 audit + LN readiness;
9. current LN Style Bible;
10. any approved LN voice baseline already established.

Only then draft.

## Allowed LN expansion

Allowed without changing canon:
- prose-native sensory detail;
- interiority that does not reveal knowledge early;
- clearer geography;
- connective tissue;
- additional mundane actions;
- dialogue needed to replace visual acting;
- breathing room;
- scene transitions;
- selectively expanded ordinary-life material;
- pacing expansion already promoted by the S1 audit.

## Requires creator/story authority

Do not invent or silently decide:
- new plot event;
- new arrival;
- new relationship status;
- new power/mechanic;
- new backstory fact;
- new wardrobe item;
- altered chronology;
- changed causal relationship;
- solved mystery;
- character motive not supported by source;
- explicit emotional category the character has not reached yet.

## Character rule

The move to prose never gives permission to smooth the cast into one LN voice.

Every expansion must grow from the character's existing:
- cadence;
- humor;
- blind spots;
- emotional range;
- social reflexes;
- knowledge;
- habits;
- pressure behavior.

## Visual continuity hardening

A prose adaptation can remain factually correct while still becoming visually under-specified. That is a production risk.

For any scene where a visual state is story-relevant, the LN must make that state explicit at the first useful point in the scene instead of relying only on implication from earlier pages.

Examples include:
- physical exhaustion, dirt, blood, injury or bandaging;
- exact story-critical prop identity;
- retained or borrowed accessories;
- room occupancy / whose belongings are where;
- wardrobe stage when it carries continuity or subtext;
- time-of-day / weather when it changes the visual meaning of the beat;
- a location state that evolves across the season.

Do not add decorative detail merely to make prose more visual. Only harden details already supported by current Story authority.

If an exact visual design is still unresolved in Story source, name the canonical object/state without inventing its final design. Downstream illustration work must resolve that design from the approved visual reference pack, not from improvised prose.

For story-critical visual beats, an illustrator should not have to infer a contradictory default state from generic wording such as `the ornament`, `dirty`, or `normal clothes` when the source already specifies something more precise.

## Source ledger inside LN documents

Each production chapter should record in its metadata:
- source episode;
- primary draft;
- applied audit/corrections;
- relevant addenda/bibles;
- chapter status.

The printed reading text does not need to expose this metadata, but Continuum must retain it.

## Review semantics

A chapter can be:
- DRAFT;
- REVIEW;
- APPROVED;
- LOCKED;
- SUPERSEDED.

Approval of LN prose approves the adaptation, not a change to shared Story Canon.
