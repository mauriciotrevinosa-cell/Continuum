# The Arrivals — S2 Slice-of-Life / Reservoir Review v0.1

**Status:** LIVED-SPACE REVIEW — RECOMMENDATIONS, NOT EPISODE LOCK  
**Date:** 2026-09-28  
**Branch:** `m3/critical-path`  
**Reviews:** `S2_PROVISIONAL_EPISODE_ROADMAP_v0.3.md`

## Purpose

Review S2 v0.3 specifically for:
- where the season already breathes;
- where lived-space is still thin;
- which reservoir ideas naturally fit S2;
- whether any idea currently deserves a new full episode;
- which ideas should remain flexible or move to S3 if unused.

This is **not** another structural rewrite.

Rule:
> Slice-of-life is added only when it makes the family, relationships, place or recovery more believable/enjoyable.

No quota.

---

# 1. Overall verdict

S2 v0.3 already contains substantial lived-space.

Existing strong breathing units:
- E04 Rainy Days;
- E09 New Combinations;
- E10 Nothing Day;
- E11 Moving Pack;
- E12 mixed work/dinner integration;
- E16 Settling In / Agott;
- E21 Festival;
- E25 intervention → healing/normalization;
- E27 Ori belonging;
- E30 Still Here;
- E32 One More Day.

Therefore:

> **Do not add a large number of standalone slice-of-life episodes.**

The primary thin zone is:

> **after Maki/Stark arrive and before G4 convergence accelerates into four-girls / Agott / Himmel / Sukuna-dream pressure.**

A secondary zone is:
> post-Sukuna healing, but current E25 can probably carry this through internal slice material rather than a guaranteed extra episode.

A tertiary zone is:
> Ori's independent belonging, best solved by embedding ordinary activities into E27/E30 rather than automatically adding an episode.

# 4. Maki / Stark / early G4 — E13–E16

## Current lived-space health: MODERATE

This is the clearest possible expansion zone.

Current flow:
```text
Maki
→ Stark
→ a few days implied
→ four girls
→ settling / Agott
→ Himmel
```

Creator already identified that Maki/Stark should have time to:
- create routines;
- feel resident;
- let Frieren slowly build trust with Maki;
- let Stark become part of daily household life;
- let G3 be the people helping newcomers now.

E15 currently compresses the "few days" into its opening.

That may be enough.

But this is the **single strongest candidate for one additional ordinary-life episode** if S2 receives one during the slice pass.

## Candidate new episode — working concept only

### `New Routines`
**Possible placement:** between current E14 and E15.

Not an arrival episode.

Possible lived material:
- Maki wakes absurdly early / household discovers her routines;
- Yuta/Maki ordinary couple-life rather than reunion emotion;
- Stark attempts chores/training/help and gets absorbed into household nonsense;
- Frieren/Maki first low-pressure recurring interaction;
- Stark/Fern/Frieren old-family habits collide with new household habits;
- G3 naturally helps Maki/Stark learn where things are;
- Coco/Anko/Umaru/etc interact with them without plot function;
- one ordinary shared activity from reservoir carries the episode.

### What reservoir could carry it?

Best candidates:
1. **baseball / improvised sport**;
2. game day;
3. repair/expansion project;
4. low-risk mixed job;
5. small local outing.

### Baseball reassessment

This is probably baseball's **best current S2 placement** if we develop it.

Why:
- G3 already belongs;
- Maki and Stark have just arrived;
- four girls have not yet expanded the cast again;
- the game can immediately reveal Maki/Stark socially;
- it gives Yuta/Maki something other than reunion;
- it gives Mikasa fun/competition;
- it lets powerless/non-athletic characters matter through rules/roles;
- G1/G2/G3 now have enough culture to teach a newcomer "our version" of a game.

But:
> baseball should only become the episode if the actual premise becomes funny/emotional enough.

Do not create `New Routines` solely to host baseball.

## Current classification
**Strongest possible new full S2 slice episode: E14.5 / New Routines.**

Not locked.

# 16. Slice-pass verdict

Solve that one problem first.
