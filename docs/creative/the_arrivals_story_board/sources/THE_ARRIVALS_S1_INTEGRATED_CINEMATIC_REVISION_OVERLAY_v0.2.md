# 1. Revision philosophy

The objective is **not** to make Season 1 longer for its own sake.

Add pages only when they improve one or more of:
- emotional causality;
- silent character interiority;
- environment / geography comprehension;
- transition quality;
- page-turn rhythm;
- acting / reaction readability;
- relationship depth;
- recurring visual motifs;
- the sense that characters actually live in the inn and settlement.

Do not add repetitive exposition, redundant dialogue or filler activities merely to increase length.

The 19 episode structures, canon outcomes and existing GREEN LIGHT decisions remain intact.

---

# 2. Production implementation rule

The first Level-4 panel scripts remain the archived base scripts.

This overlay adds **explicit insertion / expansion blocks** rather than destructively renumbering 1,227 existing pages by hand before visual composition.

For M3 / chapter-package purposes:

> **approved base panel script + this overlay = current authoritative manga script**

Continuum must not build a production chapter package from the base panel script alone if an episode is affected by this overlay.

During chapter-package materialization:
1. insert the approved revision blocks at the specified dramatic locations;
2. renumber pages sequentially;
3. preserve the same natural dramatic chapter endpoints unless the rough composition reveals a stronger equivalent cut;
4. record lineage from each inserted page back to this overlay and its source addendum;
5. retain old page/script versions non-destructively.

The chapter **count remains 56 across Season 1**. Exact page numbers of the cuts move; the dramatic cut beats remain.
